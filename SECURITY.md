# Security Policy

## Supported versions
@idleware strives to maintain the latest major versions of each project.
These are side projects, so this is a natural limitation of our development resources.

## Reporting a vulnerability

Please report vulnerabilities privately via [GitHub security advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) of the affected repo.
A PR with a fix would be great too.
